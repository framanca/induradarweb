Alarms

Current state evaluated by the PLC. Persistent history and acknowledgement are planned.

Recipes

Reserve Retain memory according to the selected count and size. Each recipe uses a STRING of the configured size plus 12 spare characters, a UDINT revision, and a global initialization flag. Capacity is checked on export and when saving in the browser.

Before changing capacity on an installed PLC: export the recipes to JSON from the HMI. Changing Retain variable dimensions or transferring another program may reset the recipe bank. Older recipes stored only in the browser are not migrated automatically: export them from the previous runtime and import them into the new one.

Initial recipes

All recipes are stored in NX Retain memory. The runtime can create, edit, apply, and export JSON copies. Saving a recipe does not change machine setpoints; press Apply to do that. When recipes are disabled, the generator omits their code and variables.
