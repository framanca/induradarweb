2. Qué es InduRadar

InduRadar es un servicio de investigación e inteligencia comercial orientado a identificar empresas, plantas industriales, proyectos, inversiones, ampliaciones, nuevas líneas, cambios organizativos, ayudas, licitaciones y otras señales que puedan generar oportunidades comerciales.

La información utilizada por InduRadar puede proceder de fuentes públicas, corporativas, administrativas, profesionales, bases de datos autorizadas y de la información facilitada directamente por los propios clientes o usuarios.

3. Qué datos podemos tratar

Según la relación con el usuario y el servicio solicitado, InduRadar puede tratar datos como:

  • nombre y apellidos;
  • empresa y cargo profesional;
  • correo electrónico profesional;
  • teléfono profesional;
  • página web corporativa;
  • ciudad, provincia, país o área geográfica de actividad;
  • información sobre productos y servicios ofrecidos;
  • sectores y tipos de empresas objetivo;
  • tecnologías, procesos y áreas de interés;
  • señales, proyectos y oportunidades que el usuario desea localizar;
  • cuentas estratégicas, clientes actuales, empresas objetivo, competidores y empresas excluidas;
  • información incluida voluntariamente en formularios, emails, documentos o solicitudes;
  • historial de solicitudes y comunicaciones;
  • datos técnicos necesarios para el funcionamiento y seguridad del servicio.

InduRadar no solicita datos especialmente sensibles. Se recomienda no incluir información relativa a salud, ideología, religión, afiliación sindical, orientación sexual, datos biométricos u otras categorías especiales de datos personales que no sean necesarias para la solicitud.

4. Finalidades del tratamiento

Los datos podrán utilizarse para:

  • gestionar formularios, consultas y solicitudes;
  • configurar el alcance de investigaciones y servicios;
  • preparar informes, búsquedas, alertas y entregables;
  • contactar con el usuario en relación con su solicitud o servicio;
  • gestionar relaciones precontractuales o contractuales;
  • mantener preferencias de investigación y seguimiento;
  • gestionar cuentas o empresas cuya vigilancia haya solicitado el cliente;
  • mejorar la calidad y funcionamiento del servicio;
  • garantizar la seguridad y prevenir usos abusivos;
  • atender obligaciones legales;
  • enviar comunicaciones comerciales cuando exista una base jurídica válida para ello.

InduRadar no utilizará la información privada facilitada por un cliente para elaborar informes destinados a otros clientes ni para revelar relaciones comerciales privadas sin autorización.

5. Bases jurídicas

El tratamiento podrá basarse en:

Ejecución de un contrato o aplicación de medidas precontractuales, cuando resulte necesario para gestionar una solicitud, preparar un servicio o ejecutar una relación comercial.

Consentimiento, cuando sea necesario solicitar una autorización específica.

Interés legítimo, cuando resulte adecuado para la seguridad del servicio, prevención de abusos, gestión de relaciones profesionales u otros tratamientos legítimos que no prevalezcan sobre los derechos de las personas afectadas.

Cumplimiento de obligaciones legales, cuando el tratamiento sea necesario por razones legales, fiscales, contables o regulatorias.

Cuando el tratamiento se base en el consentimiento, este podrá retirarse posteriormente.

6. Investigación empresarial y fuentes públicas

InduRadar realiza investigaciones sobre empresas, instalaciones industriales, proyectos, inversiones y otros acontecimientos empresariales.

Entre las fuentes utilizadas pueden encontrarse:

  • páginas web corporativas;
  • comunicados y publicaciones empresariales;
  • diarios oficiales;
  • registros públicos;
  • Registro Mercantil y BORME;
  • subvenciones y ayudas públicas;
  • contratación pública;
  • permisos, licencias y autorizaciones;
  • información ambiental y administrativa;
  • patentes, marcas y diseños industriales;
  • autoridades portuarias y organismos de infraestructuras;
  • organismos energéticos;
  • asociaciones empresariales y sectoriales;
  • centros tecnológicos;
  • ferias y eventos profesionales;
  • ofertas de empleo;
  • prensa especializada;
  • perfiles y páginas profesionales de acceso público;
  • bases de datos y servicios de información contratados legalmente.

InduRadar procura utilizar únicamente la información necesaria para la finalidad de investigación.

Cuando se traten datos profesionales de personas físicas obtenidos de fuentes externas, se intentará conservar información sobre su procedencia y fecha de verificación cuando sea posible.

InduRadar distingue en sus investigaciones entre:

  • hechos confirmados;
  • inferencias razonadas;
  • estimaciones sobre el estado o fase de un proyecto.

La información obtenida de una fuente pública o profesional no se considera automáticamente exacta, completa o actualizada, por lo que puede estar sujeta a verificación y revisión.

7. Información facilitada por clientes

Los clientes pueden proporcionar información necesaria para configurar sus investigaciones, incluyendo:

  • clientes actuales;
  • empresas objetivo;
  • cuentas estratégicas;
  • competidores;
  • empresas excluidas;
  • sectores prioritarios;
  • preferencias comerciales;
  • criterios de búsqueda;
  • información sobre proyectos o relaciones comerciales.

Esta información se utiliza para prestar y personalizar el servicio solicitado.

InduRadar procura mantener separada la información privada de cada cliente de la información empresarial obtenida de fuentes externas.

La existencia de una empresa dentro de la base de datos general de InduRadar no implica que se comparta información privada aportada por otros clientes sobre dicha empresa.

Las relaciones comerciales privadas, notas internas, pipeline, criterios de prioridad, cuentas protegidas u otra información confidencial de un cliente no se mostrarán a otros clientes sin autorización.

8. Inteligencia artificial y automatización

InduRadar puede utilizar herramientas automatizadas y sistemas de inteligencia artificial para tareas como:

  • búsqueda y clasificación de información;
  • extracción de datos;
  • resumen de documentos;
  • deduplicación;
  • identificación de empresas y proyectos;
  • detección y clasificación de señales;
  • preparación preliminar de informes;
  • priorización y organización de información.

Estas herramientas actúan como apoyo al proceso de investigación.

El contenido generado automáticamente no se considera definitivo cuando vaya a incorporarse a informes, bases de datos o decisiones comerciales relevantes sin un proceso de revisión adecuado.

InduRadar procura mantener trazabilidad sobre las fuentes, evidencias y criterios utilizados para generar sus conclusiones.

InduRadar no utiliza actualmente los datos recogidos mediante el formulario para adoptar decisiones exclusivamente automatizadas que produzcan efectos jurídicos sobre las personas o les afecten significativamente de manera similar.

9. Proveedores tecnológicos

Para prestar el servicio, InduRadar puede utilizar proveedores tecnológicos especializados.

Actualmente pueden intervenir, entre otros:

Supabase, para infraestructura de base de datos y servicios backend.

Resend, para el envío de notificaciones y correos electrónicos relacionados con las solicitudes.

GitHub, para desarrollo, alojamiento y despliegue de determinados componentes técnicos del sitio web.

En el futuro podrán incorporarse otros proveedores necesarios para servicios como infraestructura, almacenamiento, seguridad, automatización, analítica, facturación o comunicaciones.

Cuando dichos proveedores traten datos personales por cuenta de InduRadar, se procurará utilizar servicios que ofrezcan garantías adecuadas de protección de datos.

10. Transferencias internacionales

Algunos proveedores tecnológicos pueden prestar servicios desde países situados fuera del Espacio Económico Europeo o utilizar infraestructuras internacionales.

Cuando esto implique una transferencia internacional de datos personales, se utilizarán, cuando resulte necesario, mecanismos reconocidos por la normativa aplicable, como decisiones de adecuación, cláusulas contractuales tipo u otras garantías válidas.

11. Conservación de los datos

Los datos se conservarán durante el tiempo necesario para gestionar la solicitud, prestar el servicio y mantener la correspondiente relación comercial.

Posteriormente podrán conservarse durante los plazos necesarios para atender obligaciones legales o posibles responsabilidades.

Los datos correspondientes a solicitudes que no den lugar a una relación comercial podrán eliminarse o anonimizarse cuando dejen de ser necesarios.

La información estrictamente empresarial que no constituya un dato personal podrá mantenerse con fines de investigación industrial, histórico de proyectos, deduplicación, análisis sectorial y mejora de los servicios de InduRadar.

Cuando una persona ejerza su derecho de oposición o solicite la supresión de determinados datos personales, InduRadar aplicará dicho derecho cuando resulte legalmente procedente.

12. Destinatarios de los datos

InduRadar no vende datos personales.

Los datos podrán facilitarse cuando resulte necesario a:

  • proveedores tecnológicos utilizados para prestar el servicio;
  • asesores profesionales sujetos a obligaciones de confidencialidad;
  • administraciones públicas, tribunales o autoridades cuando exista una obligación legal;
  • terceros cuando sea necesario para ejecutar un servicio solicitado y exista una base jurídica adecuada.

No se compartirán con otros clientes formularios, listas privadas de cuentas, notas internas, relaciones comerciales ni información confidencial proporcionada por un cliente sin autorización.

13. Comunicaciones comerciales

InduRadar únicamente enviará comunicaciones comerciales cuando exista una base jurídica válida.

Cuando sea necesario obtener consentimiento, este será independiente de la aceptación de esta Política de Privacidad.

El usuario podrá solicitar en cualquier momento dejar de recibir comunicaciones comerciales.

La oposición a comunicaciones comerciales no impedirá recibir comunicaciones necesarias para gestionar una solicitud, contrato o servicio existente.

15. Seguridad

InduRadar aplica medidas técnicas y organizativas razonables destinadas a proteger la información frente a pérdida, alteración, destrucción, acceso no autorizado o divulgación indebida.

El acceso a credenciales, claves API y sistemas internos se limita a los componentes que los necesitan para funcionar.

No obstante, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

17. Menores

InduRadar es un servicio dirigido a empresas y profesionales y no está destinado a menores de edad.

InduRadar no pretende recopilar intencionadamente datos personales de menores.

Si se detectase que se han recibido datos de un menor sin una base jurídica adecuada, podrán ser eliminados cuando corresponda.
